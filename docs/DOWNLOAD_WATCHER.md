# 下载与文件监听

默认用 Windows Known Folder API 发现实际 Downloads，支持已迁移的下载目录。GUI 可添加任意多个目录，删除目录只停止监控，不删除文件。监控目录直接子文件，不递归。

监听 Create / Change / Rename / Delete。`.crdownload`、`.part`、`.tmp` 不是完成文件；重命名为正式文件后仍需大小和最后修改时间持续稳定。若同名 `.part` / `.crdownload` 尚在，或无法独占打开，继续等待。

使用路径、创建时间、修改时间、大小生成哈希 ID，配合持久去重，避免重复 FileSystemWatcher 事件造成重复通知。启动时已有文件不补发；watch-file 则会检查已存在文件并等待其稳定。通知包括文件名、大小和目录，不读取内容。

稳定时间默认 10 秒，可设 2–3600。稳定是启发式信号：任意程序若停止写入超过此时间且未锁文件，无法从元数据证明“永远写完”。长间歇输出请增大等待时间，或让生产程序完成后调用 send / HTTP 作为明确完成信号。

缓冲溢出会重新扫描元数据；目录不存在显示状态，创建目录后重启后台或重新应用监控设置。
