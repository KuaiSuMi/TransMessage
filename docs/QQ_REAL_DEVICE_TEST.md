# QQ 真实设备最短验收

这部分需要用户本人创建 QQ Bot，不在无凭证 CI 中伪造通过。

1. 解压 Release 并双击，完成腾讯控制台所要求的注册、权限、沙箱与白名单。
2. 填写 AppID/AppSecret，点击验证，确认“认证成功”。
3. 绑定个人私聊，再绑定一个群；群内按提示 @机器人。
4. 发送测试通知，确认两个目标各收到一次。关闭其中一个目标后再测试，确认只投递到启用目标。
5. 一键连接 Codex，重启 Codex，发一个真实请求；最终答复后确认仅一条通知。再测 Desktop/VS Code 所用版本，记录版本号；子代理/工具调用/标题生成不得产生额外通知。
6. `run -- cmd /c echo hello` 成功通知；`run -- cmd /c exit 1` 失败通知，检查终端退出码。
7. 在监控目录下载文件，临时文件阶段不通知，正式文件稳定后只通知一次。
8. 从快捷集成复制 HTTP 示例，配置环境变量 TM_TOKEN，提交一次通知。无 Token 返回 401。
9. 关闭窗口，后台保持；托盘退出后后台停止。勾选登录启动并重新登录 Windows，确认可用。
10. 在自己的 Windows 10 x64 / Windows 11 x64 机器分别解压运行。记录系统版本、QQ 机器人类型、客户端版本和 API 错误码。
11. 在「QQ 控制」绑定主人并授权一个 Desktop 会话。从手机查询、继续，记录 Desktop 是否实际消费队列；入队成功不算执行通过。
12. 切换托管模式创建测试项目会话，让 Codex 提出普通问题。在手机收到提醒后按问题码回答，检查 Codex 确认、后续结果和重复回答拒绝。确认群内与其他私聊用户不能操作。
13. 检查历史中的时间、投递状态和脱敏正文；敏感答案仅在电脑输入。断线后旧问题码必须失效。记录主动提醒是否受 QQ 权限/配额限制。

若平台拒绝主动消息，记录腾讯 error code 和控制台权限，不引入非官方协议。完成后把实际结果写入独立实机记录；不要将模拟服务结果当作腾讯实机结果。
