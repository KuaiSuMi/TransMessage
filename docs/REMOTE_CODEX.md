# QQ 控制 Codex

更新时间：2026-10-15，Asia/Shanghai。TransMessage 0.2.0。

## 开始使用

1. 在「QQ 机器人」绑定自己的私聊目标，验证发送成功。
2. 打开「QQ 控制」，选择私聊控制者，勾选启用。
3. 选择连接方式，保存并连接。程序自动发现本机 Codex 原生 exe，也可手动选择。通知功能本身不要求安装 Codex。
4. Desktop 模式：查找最近会话，核对编号、名称与目录，再授权。托管模式：选择项目目录并创建新会话。
5. 手机私聊机器人发送 `任务`。群消息、其他已绑定用户、未授权会话都不能执行控制操作。

| 私聊指令 | 行为 |
|---|---|
| 帮助 | 显示指令 |
| 任务 | 查询当前模式最多 10 个授权会话 |
| 状态 12345678 | 查询指定会话；Desktop 实时状态会明确显示未知 |
| 继续 12345678 检查测试 | Desktop 写入共享队列；托管会话启动下一轮 |
| 待回答 | 当前托管连接的有效问题 |
| 回答 A1B2C3D4 2 | 回答问题；数字对应选项编号，也支持自由文本 |
| 回答 A1B2C3D4 2 \| 额外说明 | 按顺序回答多个问题 |
| 批准 A1B2C3D4 | 仅批准消息中完整显示的本次命令 |
| 拒绝 A1B2C3D4 | 拒绝本次审批请求 |

编号可使用完整 UUID 或唯一的前 8 位。文本用空格分隔；不要把密钥发到 QQ。托管会话忙碌时不会再次启动一轮。

## 两种连接方式

**现有 Desktop · 共享消息队列**使用官方 `thread/read` 和 `thread/queue/add`。另启的本地 stdio helper 只负责读取和入队，绝不对这些会话调用 `thread/resume` / `turn/start`。Desktop 关闭或未消费队列时，入队不代表执行；本版不承诺即时打断或恢复现有窗口。

2026-10-15 在本机 Desktop Codex 0.162.0-alpha.17.2 上，已有会话的队列添加、读取、删除均通过，测试项已移除。官方 `app-server proxy` 返回 Windows socket 错误 10050，无法连接当前 Desktop 的实时通道。待输入事件也不是可可靠重放的持久历史，因此本模式不提供等待提醒和远程回答。`TransMessage.exe codex probe-desktop` 可重新检测连接及会话发现；这是诊断，不会提交提示。

**TransMessage 托管 · 实时问答**通过一个由本程序管理的 Codex app-server 创建自己的会话，使用 `workspace-write` 沙箱、`on-request` 审批和用户审核。模型、登录与项目规则沿用本机 Codex 配置；显式启用普通模式的 request_user_input 功能。不采用已有 Desktop 会话冒充托管。没有 Codex 登录或模型权限时，任务仍可能失败。

保持 TransMessage 在托盘运行；退出、停用、变更控制者或切换连接会结束托管进程。普通通知设置刷新不会重启它。已产生历史的托管会话可在重新连接后继续；创建后尚未开始第一轮的空会话可能没有持久记录，需要撤销后重新创建。

## 问题和审批

问题码绑定当前连接、会话、轮次、原始请求 ID，15 分钟有效。连接断开、轮次结束或 Codex 已处理后旧码失效。发出回答后等待 Codex 的确认；超时明确报告不确定，不自动重放。若问题已过期，回到电脑检查并重新连接/重新安排任务。

敏感问题不会把题面或选项发送到 QQ，只能在电脑的密码输入框回答。普通答案也不写进 TransMessage 通知历史，但会进入对应的 Codex 会话及其模型请求。

仅对未脱敏、未截断、完整显示且不含额外网络/权限扩展的命令提供「批准本次」。缺少完整差异的文件审批仅能拒绝；其他未实现的请求返回不支持。没有「永久批准」或「全部批准」。这版没有完整的远程审批中心。

控制指令只接受最近 5 分钟内、未来偏差不超过 1 分钟的私聊事件；每分钟最多 12 条，持久去重 7 天。输入和回复均有有界队列。手机与电脑时间严重不一致时先校时。

## 通知历史

记录普通通知和控制者私聊回复，包含时间、来源、投递状态、脱敏正文及错误。状态「送达不确定」表示网络结果不足以确认；「发送中 / 中断后结果未知」可能是进程退出造成，不自动重发。清空历史不会清除去重，也不会删除 QQ 消息。

历史保存为当前 Windows 账户绑定的 `history.dpapi`；读取只展示最近 30 天、最多 500 条，下一次写入时清理过期内容。界面一次显示最近 50 条匹配结果。该文件损坏时保留原件并报错，不自动覆盖。不要把整个数据目录发给别人。
