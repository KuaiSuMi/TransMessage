# 配置官方 QQ 机器人

1. 在 https://q.qq.com 注册并创建机器人。这一步涉及腾讯账号和验证，必须本人完成。
2. 在控制台取得 AppID / AppSecret。AppSecret 只填入 TransMessage 的密码框，不贴到 issue、聊天记录或日志。
3. 按当前控制台要求配置可测试的成员和群、群/私聊事件权限、IP 白名单等。本软件不绕过腾讯权限。
4. GUI 中选择与控制台相符的正式/沙箱 API，保存并验证。认证成功只表示取得 Token，不代表拥有主动消息权限。
5. 为私聊生成绑定码，在 QQ 向机器人发送准确指令。为群聊生成新码，在目标群 @机器人后发送。
6. 绑定码 5 分钟有效，最多允许 10 次匹配尝试，只允许当前选择的私聊/群类型，成功后立即销毁。刷新目标查看结果。
7. 点击测试，确认所有勾选目标都收到消息。可给不同目标命名、停用或移除。

绑定仅保存官方事件提供的用户/群标识，普通用户不需要理解或手填 OpenID。绑定确认是对当前消息的被动回复；实际任务完成消息是主动发送，二者权限可能不同。

连接采用官方 SDK 当前实现的 WebSocket Gateway。若你的机器人只允许其他接入方式，或平台返回权限不足，诊断会显示状态；本版没有云 relay 或非官方协议兜底。账号权限、主动消息额度和有效会话要求以当前腾讯控制台及错误码为准。
